CHAOS GREMLINS COMMUNITY WEBSITE — YAZ UPDATES

Files
- index.html: the website prototype

Attachment updates
- Post composers across community posts, announcements, vents, and anonymous confessions accept multiple file attachments of any file type.
- Moderator applications also accept multiple attachments.
- Images are previewed in post cards, and other files appear as attachment links.
- The browser-only prototype currently limits attachments to 5 files per submission and 2 MB per file.

Important limitations
- This is a front-end prototype. Posts and attachments are stored in the current browser only; they are not shared across members or devices.
- Shared messaging and attachment uploads require secure member accounts, server-side authorization, and shared file storage. The moderator-only chat remains locked until that secure backend exists.
- Voice rooms use external Jitsi links; moderator-only access is not enforced by this static website.
- Automatic TikTok live alerts and live moderator application delivery require backend integrations.

To publish
1. Upload index.html and README.txt to the root of your GitHub repository, replacing the previous versions.
2. Commit the changes.
3. Enable GitHub Pages in the repository settings if it is not already enabled.
